# Quickshell notifications and OSD

This setup uses Quickshell's native `NotificationServer` to own the session's
`org.freedesktop.Notifications` D-Bus service and render notification cards.
It replaces SwayNC, mako, dunst and fnott. The old SwayNC CSS and JSON files are
not used by this UI; notification and OSD colors are read from the live
Quickshell `Theme` palette generated by Wallust / `update_theme`.

## One-time migration

1. Run `~/.config/quickshell/scripts/enable-quickshell-notifications.sh`.
2. Remove old notification-daemon startup lines from Hyprland.
3. Restart Quickshell and test with:

   ```sh
   notify-send "Quickshell test" "Notifications are now handled by Quickshell."
   ```

Only one process should own `org.freedesktop.Notifications`.

## Notification settings

Control Center → Notifications contains Do Not Disturb, an enable switch and a
dismiss-all action. Incoming notifications appear bottom-centre of the focused
monitor. Low-priority notifications expire after 3 seconds, normal
notifications after 5 seconds, and critical notifications remain until
dismissed. Application-specified timeouts are respected. Action buttons invoke
their original notification actions.

## OSD

Volume, microphone and brightness changes display a floating OSD card and,
when `osdOnClock` is enabled, briefly replace the date/time in the bar. The
floating card uses the current `Theme.primary`, `Theme.surface`, foreground and
outline colors, so its glyph and progress indicator adapt immediately when the
Wallust palette changes. Status updates such as Wi-Fi, Bluetooth, airplane
mode, touchpad, display and power-profile changes use the same OSD.

The native `prgnotifier` helper now passes the measured percentage and mute
state over Quickshell IPC. This avoids waiting for PipeWire or the backlight
singleton to refresh before drawing the OSD.

Build and install the helper with:

```sh
~/.config/quickshell/scripts/build-native-tools.sh
```

Other scripts can show a status message with:

```sh
~/.config/quickshell/scripts/qs-osd "Airplane mode enabled"
quickshell ipc call osd status "Wi-Fi connected"
```

The OSD timeout is controlled by `osdTimeoutMs`; clock replacement is
controlled by `osdOnClock` in `~/.config/quickshell/settings.json`.
